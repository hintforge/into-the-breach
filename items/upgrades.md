# Into the Breach -- Upgrades

**status:** research-integrated
**last_reconciled:** 2026-06-02

The reactor-core upgrade system. Weapon-specific upgrade tiers and costs are listed per weapon in `items/weapons.md`; priority guidance cross-references `items/builds.md`.

## Reactor cores

Reactor cores are the primary upgrade currency. You can install up to **9 cores** per mech; TV Tropes notes the effective ceiling is **11 cores** once pilot "+1 Mech Reactor" and Mafan's reactor bonus stack on top. Cores can be freely redistributed at any time (Undo install). [Confirmed: 2 sources]

## Core sources

- Every Time Pod always yields 1 core (islands 1–2 = 1 pod, islands 3–4 = 2 pods).
- Perfect Island reward.
- "Protect the Robotics/Defense Lab" missions — the only direct-core missions.
- Buy for **3 Reputation** at island end (cores are the most valuable purchase — worth 3 rep).
- Pilot "+1 Mech Reactor" bonus skill; Mafan grants +1.

## Universal upgrade nodes (any mech)

- **+2 HP**, **+1 Move**, **+1 Reactor** — available to every mech.
- **+3% Grid DEF** — via the pilot bonus skill, not a core node.
- Weapon-specific upgrades are built into each weapon and priced per tier in cores (see `items/weapons.md`).
